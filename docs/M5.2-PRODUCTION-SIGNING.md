# M5.2 production signing (operator)

## M5.2a

- Offline source → validate → generate deterministic unsigned payload
- Generated payload is **local/gitignored** under `generated-candidates/`
- GitHub Pages publishes from `main` at repository root (`/`)

## M5.2b

1. Regenerate + revalidate candidate locally (`tools\prepare-v3-candidate.bat`)
2. Production-sign with standalone `registry-sign` launcher (**outside Gradle JavaExec**)
3. Verify signed envelope locally
4. Copy signed envelope to `v1/catalog-schema-v3/current.json`
5. Leave `v1/current.json` byte-unchanged
6. Reviewed commit + push

### Why not Gradle `:run`?

`gradlew :tools:registry-sign:run` launches the JVM via Gradle `JavaExec`.
That child process typically has `System.console() == null`, so encrypted PKCS#8
passphrase prompting fails even when started from a real `cmd.exe`.

### Recommended Windows operator flow

Sibling layout required:

```
<WORKSPACE>/
  ai-mobile/android-app/
  ai-mobile-registry/tools/
```

```bat
cd /d "<ai-mobile-registry>\tools"
prepare-v3-candidate.bat
probe-signer-console.bat
sign-v3-candidate.bat "<EXTERNAL_PKCS8_PEM>" "<PINNED_PUBLIC_SPKI_PEM>" [generatedAtEpochMillis] <registryVersion>
```

`registryVersion` (4th argument) is **required** and must be a positive integer.
Do not rely on a silent default (prevents accidental re-sign of an old version).

Wrappers resolve `ai-mobile` as a **sibling** of `ai-mobile-registry`
(via shared `_resolve-sibling-paths.bat`), independent of the current working directory.

Host JDK: User `JAVA_HOME` should point at Eclipse Temurin **21+**. Machine Java 17 may
remain installed but must not be the active production tool JDK for Gradle/signing.

`sign-v3-candidate.bat`:

1. Ensures process-local `JAVA_HOME` is JDK 21+ via `_ensure-java21.bat`
   (rejects Java 17; selects Adoptium 21+; never `setx`)
2. Runs Gradle `:tools:registry-sign:installDist` (build only)
3. Re-asserts JDK 21+ after Gradle
4. Writes non-secret args to `%TEMP%\aimobile-registry-sign-args.txt`
5. Invokes `...\build\install\registry-sign\bin\registry-sign.bat --args-file ...`
   **directly** from cmd.exe so `System.console()` works
6. On success only: verifies output file exists and is non-empty, then prints the path
   (`%TEMP%\catalog-schema-v3-current.json`, not Pages path). Non-zero exit otherwise.

Console probe / non-production test:

```bat
probe-signer-console.bat
test-sign-console.bat
```

Passphrase policy:

- Interactive hidden console prompt only (`console.readPassword`)
- Never CLI args, environment variables, source, docs, logs, Git, or args files

After self-verification PASS, copy the signed envelope to:

`v1/catalog-schema-v3/current.json`

`CatalogFeedId` is not part of the signed message (ADR-0014).
