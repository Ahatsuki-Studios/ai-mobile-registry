# M5.2 production signing (operator)

## M5.2a (this slice)

- Offline source → validate → generate deterministic unsigned payload
- Generated payload is **local/gitignored** under `generated-candidates/`
- Test-key signing optional
- **No** production private key
- **No** production-signed envelope
- **No** publication / push

GitHub Pages for this repo publishes from `main` at repository root (`/`).
Therefore unsigned candidates must remain ignored so `git add .` cannot publish them.

## M5.2b (later)

1. Regenerate + revalidate candidate locally (`tools\prepare-v3-candidate.bat`)
2. Production-sign via args file (safe for Windows paths with spaces)
3. Copy signed envelope to `v1/catalog-schema-v3/current.json`
4. Leave `v1/current.json` byte-unchanged
5. Reviewed commit + push

Passphrase policy:

- Interactive console prompt only
- Never CLI args, environment variables, source, docs, logs, Git, or generated files

### Recommended Windows operator flow

```bat
cd /d "<ai-mobile-registry>\tools"
prepare-v3-candidate.bat
sign-v3-candidate.bat "<EXTERNAL_PKCS8_PEM>" "<PINNED_PUBLIC_SPKI_PEM>" <EPOCH_MILLIS>
```

`sign-v3-candidate.bat` writes one-arg-per-line to `%TEMP%` and invokes:

```bat
gradlew.bat :tools:registry-sign:run -PtoolArgsFile="%ARGS_FILE%"
```

Do **not** pass payload/key/out paths through Gradle `--args="..."` when paths contain spaces.

After self-verification PASS, copy the signed envelope to:

`v1/catalog-schema-v3/current.json`

`CatalogFeedId` is not part of the signed message (ADR-0014).
