# Production schema-v3 authoring source

This directory is the **publication SSoT** for the future PRODUCTION_V3 feed.

Flow:

1. Edit `catalog.json` (human-maintained metadata)
2. Run offline `registry-prepare generate` from the AI Mobile tools
3. Review `generated-candidates/m5.2a-production-v3-catalog.json`
4. M5.2b: production-sign the generated bytes → write `v1/catalog-schema-v3/current.json`

Rules:

- App `testFixtures` are **not** the production SSoT
- Do **not** hand-edit signed `current.json` envelopes
- First live v3 feed is MiniCPM-only (rollout policy, not permanent schema law)
- Leave `v1/current.json` (legacy v2) byte-unchanged until an explicit v2 republish
